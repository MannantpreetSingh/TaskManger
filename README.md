# Task Manager

A simple and lightweight **Task Manager** web application built using **PHP** and **MySQL**. It allows users to register, log in, and manage their daily tasks through a simple and user-friendly interface.

This project demonstrates **CRUD (Create, Read, Update, Delete)** operations, user authentication, session management, and database integration using PHP and MySQL.

---

## Features

- User registration
- User login and authentication
- Session-based user management
- Add new tasks
- View tasks
- Edit existing tasks
- Delete tasks
- User-specific tasks
- Password hashing
- Simple and responsive interface
- MySQL database integration
- Health-check endpoint for deployment monitoring
