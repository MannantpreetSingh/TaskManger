# Task Manager

A simple and lightweight **Task Manager** web application built using **PHP** and **MySQL**. It helps users organize and manage their daily tasks efficiently by providing basic task management features through an easy-to-use interface.

This project demonstrates the implementation of **CRUD (Create, Read, Update, Delete)** operations using PHP and MySQL, making it a great learning project for beginners.

---

## Features

-  Add new tasks
-  View all tasks
-  Update existing tasks
- Delete tasks
-  Simple and user-friendly interface

---

## Tech Stack

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3
- **Server Environment:** XAMPP
